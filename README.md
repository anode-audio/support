## Reporting bugs

Use the **Issues** tab and pick the form for your product. It asks for
the details that matter (version, platform, host, how to reproduce). A
good report gets a fix faster.

No GitHub account? Email support@anode-labs.com with the same details.
The [contact page](https://anode-labs.com/contact/#report-by-email) has
a link that fills in the template for you.

## Requesting features

Same **Issues** tab, "Feature request" form. Be specific about the use
case: a real scenario is far more useful than a generic "please add X".

## Discussions

Questions, tips, preset sharing and "does this count as a bug?" go in
**Discussions**. Bug reports still go under Issues.

## Source code

This repo only holds issues and discussions. Bitcrust, Mecate, Earshot
and Bruma are closed source; any reference to internal files or commits
in a comment is for context only. The open-source projects
([asma](https://github.com/anode-audio/asma),
[Mecate for Decent Sampler](https://github.com/anode-audio/mecate-decentsampler))
live in their own repos.

This repo was called `anode-audio/bitcrust` until November 2026. Old
links redirect here, and issue numbers didn't change.
